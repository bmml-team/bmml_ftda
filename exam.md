# Список вопросов к экзамену по курсу «Байесовские методы в анализе данных», осень 2026

1. Байесовский подход к теории вероятностей. Оценка параметров в байесовском и частотном подходе. Примеры байесовских рассуждений.
2. Сопряжённые распределения. Примеры. Экспоненциальный класс распределений, его свойства.
3. Решение задачи выбора модели по Байесу. Обоснованность модели. Полный байесовский вывод.
4. Вероятностная модель линейной регрессии. Байесовская модель линейной регрессии. Метод релевантных векторов для задачи регрессии (идейно).
5. ЕМ-алгоритм в общем виде. Примеры применения.
6. Задача уменьшения размерности в данных. Вероятностная модель главных компонент, её обучение с помощью метода максимального правдоподобия и ЕМ-алгоритма.
7. Методы генерации выборки из одномерных распределений.
8. Методы MCMC для оценки статистик вероятностных распределений. Теоретические свойства марковских цепей.
9. Схема Метрополиса-Хастингса и схема Гиббса. Примеры использования.
10. Вариационный автокодировщик. Сравнение GAN-ов и VAE.
11. Дискретные диффузионные модели. Определение прямого и обратного процесса, вывод функции потерь, алгоритм обучения. 

# Теоретический минимум

Вопросы из этой части охватывают базовые математические понятия и алгоритмы, которые активно используются в курсе. Незнание ответа на любой вопрос из данной части автоматически влечёт за собой неудовлетворительную оценку по экзамену.

- Базовые понятия. Математическое ожидание, мода, медиана, дисперсия и матрица ковариации случайной величины. Функция правдоподобия, метод максимального правдоподобия, его недостатки.
- Стандартные распределения: Бернулли, нормальное, равномерное, бета, биномиальное, экспоненциальное, Пуассона, гамма.
- Условная вероятность. Правило суммы и произведения для вероятностей. Формула Байеса. Независимость случайных величин. 
- Сопряжённые распределения: определение и примеры. Связь сопряжённых распределений и полного байесовского вывода.
- Метод релевантных векторов для задачи регрессии: постановка задачи, зачем используется, с помощью какого метода обучается.
- Дивергенция Кульбака-Лейблера, её основные свойства и использование для поиска аппроксимирующих распределений.
- Общая схема ЕМ-алгоритма: какая задача решается и как именно? Формулы для оптимизируемого функционала, для Е и М шагов.
- Методы Монте-Карло, какая связь с методами семплирования.
- Алгоритм Метрополиса-Хастингса: какая задача решается и как именно?
- Задачи генеративного моделирования. Подходы к решению.
- Вариационный автокодировщик: модель и как ее тренировать.
- Модель диффузии: как ее обучить.
